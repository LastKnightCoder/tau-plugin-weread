# 微信讀書

把你在微信讀書裡的書架、劃線和想法搬進 Tau。讀書時隨手記下的句子，可以在這裡搜到、在文章裡引用，也能一鍵變成卡片或問題。

## 三步開始

1. **裝好外掛**：在外掛中心安裝「微信讀書」，再到外掛頁的「已安裝」裡開啟它的開關。電腦上側邊欄會多出「微信讀書」入口，手機上在「我的」頂部的功能宮格裡，不用重啟。
2. **連上帳號**：開啟「微信讀書」，點「開啟取得頁」，在微信讀書的「AI 技能」頁複製 API Key，貼回來。驗證通過後會自動同步一次書架。
3. **開始翻筆記**：點開任意一本書，就能看到按章節排好的劃線和想法。

## 可以做什麼

- **逛書架**：按「在讀 / 讀完 / 未開始」「有筆記」篩選，按最近閱讀、閱讀進度、筆記數等排序，封面和列表兩種檢視隨意切換，也可以直接搜書名或作者。
- **看筆記**：書籍頁左側是目錄，右側按章節列出劃線，你寫的想法會高亮顯示，方便一眼找到。
- **用筆記**：滑鼠移到一條劃線上，可以複製或轉為卡片；也可以把整本書的筆記複製為 Markdown，或點「在微信讀書中開啟」回到原書。
- **引用筆記**：同步過來的劃線和想法會變成 Tau 裡的摘錄，能被搜尋到，也能在文章裡引用；點開引用會直接跳回這本書的對應位置。

## 在手機上

- **書架**：頂部一行是書的數量、累計閱讀時長和同步按鈕，放大鏡用來搜書名或作者；同步旁的 ⋯ 裡可以看上次同步的結果、全量重新同步，或去「帳號與連線」換 Key。下面是分類，最右邊的按鈕可以按狀態篩選、換排序、切換封面和列表。
- **看筆記**：書名下方有「在微信讀書中開啟」和「重新拉取」，更多操作在 ⋯ 裡，比如把整本書的筆記複製為 Markdown。往下翻時，篩選列會停在頂部，右邊的「目錄」按鈕顯示目前章節，點開可以跳到別的章節。
- **用筆記**：點一條劃線，可以轉為卡片、複製劃線，或連同想法一起複製；長按可以只選其中幾個字。
- 電腦上連過微信讀書，再用雲端同步把資料庫同步到手機，手機上開啟就是已連線的狀態，不用再填 API Key。

## 同步

- App 回到前景後會自動增量同步，不跳出成功提示；重複恢復訊號會合併，同步期間再次返回前景會在本輪結束後補一輪。停用外掛後不再自動同步。

- 平時點書架右上角的「同步」就行，它只更新新加的書，以及最近讀過、記過筆記的書，速度很快。
- 覺得資料不對時，點「同步」旁邊的小箭頭（手機上是 ⋯），選「全量重新同步」，會把整個書架重新拉一遍（書多時會慢一些，手機上同步期間盡量不要切到背景）。
- 在微信讀書裡新劃了線，回到對應的書點「重新拉取筆記」即可看到。

## 常見問題

**斷網了還能看嗎？** 能。已經同步過的劃線和想法都存在本機，離線也能看、能引用。只有整本書的書評，和沒有對應原文的想法，需要連網時才能顯示。

**提示「API Key 已失效」怎麼辦？** 點書架上提示條裡的「重新填寫」（或到外掛設定的「帳號與連線」，手機上也可以從書架的 ⋯ 進入），貼上新的 Key 即可，之前的書架和筆記都還在。

**在微信讀書裡把書移出書架了會怎樣？** 下次同步時，這本書的摘錄會被隱藏；以後再加回書架，摘錄和文章裡的引用都會原樣還原。

**停用或中斷外掛，筆記會丟嗎？** 不會。已經同步過來的摘錄會一直保留，文章裡的引用照常可用。

**換了資料庫為什麼要重新填 Key？** API Key 和書架是按資料庫分開保存的，每個資料庫需要單獨連線一次。

## 小提醒

- API Key 相當於你的帳號憑證，不要發給別人，也不要貼在截圖或問題描述裡。
