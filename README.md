# 微信读书

把你在微信读书里的书架、划线和想法搬进 Tau。读书时随手记下的句子，可以在这里搜到、在文章里引用，也能一键变成卡片或问题。

## 三步开始

1. **装好插件**：在插件中心安装「微信读书」，再到插件页的「已安装」里打开它的开关。电脑上侧边栏会多出「微信读书」入口，手机上在「我的」顶部的功能宫格里，不用重启。
2. **连上账号**：打开「微信读书」，点「打开获取页」，在微信读书的「AI 技能」页复制 API Key，粘贴回来。校验通过后会自动同步一次书架。
3. **开始翻笔记**：点开任意一本书，就能看到按章节排好的划线和想法。

## 可以做什么

- **逛书架**：按「在读 / 读完 / 未开始」「有笔记」筛选，按最近阅读、进度、笔记数等排序，封面和列表两种视图随意切换，也可以直接搜书名或作者。
- **看笔记**：书籍页左侧是目录，右侧按章节列出划线，你写的想法会高亮显示，方便一眼找到。
- **用笔记**：鼠标移到一条划线上，可以复制或转为卡片；也可以把整本书的笔记复制为 Markdown，或点「在微信读书中打开」回到原书。
- **引用笔记**：同步过来的划线和想法会变成 Tau 里的摘录，能被搜索到，也能在文章里引用；点开引用会直接跳回这本书的对应位置。

## 在手机上

- **书架**：顶部一行是书的数量、累计阅读时长和同步按钮，放大镜用来搜书名或作者；同步旁的 ⋯ 里可以看上次同步的结果、全量重新同步，或去「账号与连接」换 Key。下面是分类，最右边的按钮可以按状态筛选、换排序、切换封面和列表。
- **看笔记**：书名下方有「在微信读书中打开」和「重新拉取」，更多操作在 ⋯ 里，比如把整本书的笔记复制为 Markdown。往下翻时，过滤条会停在顶部，右边的「目录」按钮显示当前章节，点开可以跳到别的章节。
- **用笔记**：点一条划线，可以转为卡片、复制划线，或连同想法一起复制；长按可以只选其中几个字。
- 电脑上连过微信读书，再用云端同步把资料库同步到手机，手机上打开就是已连接的状态，不用再填 API Key。

## 同步

- App 回到前台后会自动增量同步，不弹出成功提示；重复恢复信号会合并，同步期间再次返回前台会在本轮结束后补一轮。停用插件后不再自动同步。

- 平时点书架右上角的「同步」就行，它只更新新加的书，以及最近读过、记过笔记的书，速度很快。
- 觉得数据不对时，点「同步」旁边的小箭头（手机上是 ⋯），选「全量重新同步」，会把整个书架重新拉一遍（书多时会慢一些，手机上同步期间尽量不要切到后台）。
- 在微信读书里新划了线，回到对应的书点「重新拉取笔记」即可看到。

## 常见问题

**断网了还能看吗？** 能。已经同步过的划线和想法都存在本地，离线也能看、能引用。只有整本书的书评，和没有对应原文的想法，需要联网时才能显示。

**提示「API Key 已失效」怎么办？** 点书架上提示条里的「重新填写」（或到插件设置的「账号与连接」，手机上也可以从书架的 ⋯ 进入），粘贴新的 Key 即可，之前的书架和笔记都还在。

**在微信读书里把书移出书架了会怎样？** 下次同步时，这本书的摘录会被隐藏；以后再加回书架，摘录和文章里的引用都会原样恢复。

**停用或断开插件，笔记会丢吗？** 不会。已经同步过来的摘录会一直保留，文章里的引用照常可用。

**换了资料库为什么要重新填 Key？** API Key 和书架是按资料库分开保存的，每个资料库需要单独连接一次。

## 小提醒

- API Key 相当于你的账号凭证，不要发给别人，也不要贴在截图或问题描述里。
